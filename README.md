# 🚀 Khall Backend

Khall Backend is a scalable REST API built with Node.js, Express, and MongoDB, designed to power a modern food ordering application with secure, fast, and efficient server-side operations. 

The system includes authentication and authorization using Firebase, along with secure password hashing using bcrypt.It's codebase is maintainable, scalable, and production-ready.

This API supports full CRUD operations for food items and orders, and is optimized to serve frontend applications such as React or Next.js, ensuring fast response times, proper validation, and reliable error handling.

---

## 🛠️ Tech Stack

- Node.js  
- Express.js  
- JavaScript  
- firebase  
- REST API  

---

## ✨ Key Features

- 🔐 Secure Authentication & Authorization system  
- 👨‍💼 Role-based access control (Admin, Student)  
- 🍔 Full CRUD operations for food items  
- 🗄️ MongoDB database 
- ⚡ High-performance and optimized REST APIs  
- 🛡️ Secure password  
- 🚨 Global error handling and validation system  
- 🌐 Environment-based configuration using dotenv  
- 📦 Scalable and maintainable project structure  
- 🔗 Fully RESTful API designed for frontend integration
